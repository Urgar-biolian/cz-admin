## 功能特性

### 核心功能
- 📋 **获奖者列表展示** - 表格形式展示所有获奖者
- 🔍 **按姓名搜索** - 支持模糊搜索
- 🏆 **按获奖等级筛选** - 支持国一、国二、国三、省一、省二筛选
- ➕ **新增获奖者** - 支持添加新的获奖者记录
- ✏️ **编辑获奖者** - 支持修改现有获奖者信息
- 🗑️ **删除获奖者** - 支持删除获奖者记录
- 📤 **头像上传** - 支持上传获奖者头像

### 数据字段
- **ID** - 获奖者唯一标识
- **姓名** - 获奖者姓名
- **比赛名称** - 参加的比赛名称
- **获奖等级** - 获得的奖项等级
- **头像** - 获奖者头像
- **创建时间** - 记录创建时间

## 运行方式

### 方式1: 使用Mock数据（推荐开发环境）

1. 确保项目已安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm run dev
```

3. 访问蓝桥杯获奖者管理页面：
```
http://localhost:3100/#/lanqiao-winner
```

### 方式2: 连接真实后端

1. 确保后端服务运行在 `http://localhost:3000/api`
2. 后端需要实现完整的API接口（参考API文档）
3. 启动前端项目即可正常使用

## API接口说明

### 基础信息
- **基础URL**: `http://localhost:3000/api`
- **认证方式**: Bearer Token（管理员操作需要）
- **数据格式**: JSON

### 主要接口
- `GET /winners` - 获取所有获奖者
- `POST /winners` - 创建获奖者
- `PUT /winners/:id` - 更新获奖者
- `DELETE /winners/:id` - 删除获奖者
- `GET /winners/filter/award` - 按获奖等级筛选
- `GET /winners/stats` - 获取统计数据

## 技术栈

- **前端框架**: Vue 3 + TypeScript
- **UI组件库**: Ant Design Vue
- **HTTP客户端**: Axios
- **状态管理**: Pinia
- **路由**: Vue Router
- **构建工具**: Vite

## 常见问题

### Q: 为什么修改数据后会退出登录？
A: 这是因为API请求失败触发了401错误处理。现在已添加Mock数据，不会出现此问题。

### Q: 数据没有保存怎么办？
A: 确保后端服务正常运行，或者使用Mock数据进行开发测试。

### Q: 如何添加更多功能？
A: 可以参考现有的API接口和前端代码，按照相同的模式进行扩展。
